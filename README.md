# Christmas Snow Globe

An interactive Three.js Christmas snow globe with a cabin, snowman, falling snow, Santa's gift delivery, touch gestures and optional device-motion controls.

## Run locally

Install Node.js 22 and pnpm 10, then run `pnpm install --frozen-lockfile` and `pnpm dev`. Build with `pnpm build`.

The production version is available at https://arctic-weather-nyc-prototype.vercel.app/.
