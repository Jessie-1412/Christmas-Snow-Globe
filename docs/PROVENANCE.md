# Arctic Weather v0.2 provenance

The current workspace started from StarKnightt/nyc-snow-globe, whose README declares MIT licensing. The user's production deployment was inspected before editing: dpl_8zaX5TYtw7GRygjch5v3sntuUd5B, asset index-DNO37ui6.js.

The archived v0.1 patch returned incomplete data through the deployment file connector. Its cabin, trees, pond, terrain and berry details were recovered from that deployed executable into src/arctic.js; scripts/restore-v01.cjs documents the extraction. New work lives in typed, separately named modules. The old primitive fox is not used.

Fox.glb is sourced from KhronosGroup/glTF-Sample-Assets/Models/Fox/glTF-Binary/Fox.glb. 162852 bytes, 1728 non-indexed vertices (576 triangles), one skinned mesh, 24 joints, one 1024×1024 texture, three clips. Only the Survey clip plays. PixelMannen mesh CC0; tomkranis rig/animation and AsoboStudio/scurest conversion CC BY 4.0. Adaptations and links are public at /credits.html and /FOX-CREDITS.md.

The 1DesignTool candidate was evaluated but is not included in the deployed product. No paid assets were purchased. No generated static image is used as a substitute for live 3D or verification captures.
