Let it snow

Let it snow · v0.2.3

Scene foundation: NYC Snow Globe, StarKnightt (MIT, as declared in the upstream README). Built with Three.js (MIT).

The current character is a Christmas snowman modeled in code for Let it snow, with no external model asset. Snowfall and shake simulation match the original 4,500-particle system.

Archived v0.2 fox credits (the fox is not loaded in v0.2.1): PixelMannen (2014), CC0 1.0. Rigging & animation: tomkranis (2014). glTF conversion: @AsoboStudio and @scurest (2017), CC BY 4.0.

Original Fox asset and license details. Modifications for Let it snow: ivory winter coat, softer vertex normals, resized placement and slower Survey animation. This is a stylized winter-coat adaptation of the original fox, rather than a biologically exact polar fox model.

Cabin, terrain, trees, snow and backdrop are constructed in 3D or drawn in code. The glass uses a thin transmissive shell plus restrained Fresnel highlights; interior lens magnification is an artistic approximation.
